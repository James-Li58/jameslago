How to Update

怎麼把新作品放上來

這個網站不需要資料庫，作品清單是由你的照片資料夾自動產生的。

  1. 把照片丟進 images 資料夾。在 D 槽的「Lego作品」資料夾上按右鍵複製，然後貼到網站資料夾裡的 images 裡面就好。一個作品一個子資料夾，資料夾名稱就是作品名稱。
  2. 雙擊 build-works.bat。它會自動掃描 images 裡的所有照片，重新產生作品清單，分類也會依資料夾結構自動分好。
  3. 重新整理瀏覽器。新作品就會出現在網站上，完成。

檔名建議用 01-封面.jpg、02-側面.jpg 這樣的開頭數字，數字最小的那張會當作封面圖。

作品資料夾長這樣

images/
├─ 城市天際線/
│   ├─ 01-封面.jpg
│   ├─ 02-側面.jpg
│   └─ 03-細節.jpg
├─ 復古咖啡車/
│   └─ 01-封面.jpg
└─ 積木恐龍/
    ├─ 01-封面.jpg
    └─ 02-背面.jpg

資料夾名稱 = 作品名稱，分類可以另外在 works.js 調整。
